# ADS Skill Reference Index

## File Map

- `search_syntax.md`: core ADS query syntax, operators, ranges, wildcard/fuzzy usage.
- `solr_fields_operators.md`: field/operator selection strategy and commonly used fields.
- `search_parser.md`: advanced parser usage and debugging workflow.
- `api_basics.md`: authentication, base URL, core search endpoint, request template.
- `api_endpoints.md`: endpoint families and endpoint selection guidance.
- `api_examples.md`: Python/shell example map and reusable execution pattern.

## Quick Lookup by Need

- Need exact query grammar: open `search_syntax.md`.
- Need allowed fields/operators: open `solr_fields_operators.md`.
- Need advanced parser behavior: open `search_parser.md`.
- Need auth/request structure: open `api_basics.md`.
- Need endpoint choice: open `api_endpoints.md`.
- Need practical examples: open `api_examples.md`.
