# Scientific study notes

These notes use **note-style**, a shared reading format for scientific
summaries and engineering documentation. Each project keeps its own source
files and subject hierarchy while using the same reading conventions.

## Reading the notes

The navigation on the left lists the project's topics. The page outline
identifies sections within the current note. On narrow screens, both remain
available through the navigation controls.

Begin with [Signal and noise](signal_noise.md) for an example of a scientific
note containing assumptions, mathematical notation, a parameter table, and
a short code example.

## Appearance

The initial appearance is dark. The theme control cycles through light,
system preference, and dark, preserving a reader's selection when browser
storage is available.

The font configuration includes Chinese-capable fallbacks. The final font
assets and mixed-language typography will be refined using real project
documents.
