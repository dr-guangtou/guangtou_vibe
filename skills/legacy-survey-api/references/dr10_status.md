# DR10 Status Snapshot

Source: https://www.legacysurvey.org/status/

## Key Points

- Legacy Surveys provide optical imaging and catalogs used as DESI imaging inputs.
- The sky footprint is mostly high Galactic latitude with exclusions in high-extinction and crowded-plane regions.
- The status page tracks imaging progress and effective area maps by survey component.

## Practical Use

- Use status context to explain regional depth/coverage differences.
- Validate whether a target coordinate sits in supported footprint before issuing data URL requests.
