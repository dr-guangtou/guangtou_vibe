# DR10 Description Summary

Source: https://www.legacysurvey.org/dr10/description/

## Key Points

- DR10 is the current Legacy Surveys release for imaging and source catalogs.
- Processing includes calibrated coadds, source detection, and Tractor model fits.
- DR10 provides both image products and catalogs intended for large-scale target selection and science analysis.

## Data Product Families

- Coadded image layers and cutouts.
- Brick-level Tractor catalogs.
- Sweep catalogs for larger-area analyses.

## Practical Use

- Choose Tractor catalogs for detailed, brick-scoped analysis.
- Choose sweeps for broad statistical selections.
